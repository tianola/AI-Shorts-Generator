ClipForge is a desktop tool that cuts a user's own long video into vertical shorts on that same machine. Login Kit: the user presses "Connect TikTok" in settings, TikTok's OAuth consent page opens (authorization code with PKCE/S256), the redirect returns to http://localhost:5001/api/tiktok/oauth2callback on their own machine, tokens are stored in a local file only the user can read, and the app shows the connected @handle. Content Posting API with video.upload: after the user watches the finished clip and presses "Publish", the app runs the upload-to-inbox flow (POST /v2/post/publish/video/init, chunked PUT with Content-Range) and polls the publish status endpoint. The clip lands in the creator's TikTok inbox and a human taps post there; the app never publishes alone. user.info.basic reads the connected account's username and avatar so the UI can show which account is connected. No stats, profile or video-list data is fetched and no analytics runs.
