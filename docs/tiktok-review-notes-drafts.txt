ClipForge is a desktop tool that cuts a user's own long video into vertical shorts on that same machine. Login Kit: the user presses "Connect TikTok" in settings, TikTok's OAuth consent page opens (authorization code with PKCE/S256), the redirect returns to http://localhost:5001/api/tiktok/oauth2callback on their own machine, tokens are stored in a local file only the user can read, and the app shows the connected @handle. Content Posting API: the user reviews each rendered clip and presses "Publish"; the app creates a DRAFT post through the direct-post endpoint (POST /v2/post/publish/, chunked PUT with Content-Range, then the publish status endpoint) so the clip opens inside TikTok as a draft that the creator edits or taps to post. Nothing publishes without that press. user.info.basic reads the connected account's username and avatar to show which account is connected. No stats, profile or video-list data is fetched and no analytics runs.
